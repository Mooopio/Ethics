Phase 1 — Deep Understanding

Every concept from Lecture 5, explained simply with analogies.

What is Malware?

Malware = "malicious software." It's an umbrella term covering viruses, worms, Trojans, logic bombs, adware, and spyware.

Modern malware can steal passwords, personal information, and identities — and in some cases damage hardware.

Think of malware as a family name (like "vehicles"). Viruses, worms, and Trojans are the different "models" within that family, each with different behavior.

Rootkits

A rootkit hides deep inside core system components so antivirus scanners can't see it. Techniques: renaming a malicious file to look like a legitimate program, and altering other files so the malware doesn't show up or run normally.

Like a burglar who not only breaks in, but also edits the security camera footage and wears a staff uniform.

Viruses

The best-known malware type. A virus replicates and attaches itself to other files. Crucially, it usually needs a user action (opening a file, running a program) to start infecting.

What a virus can do:

  • Alter data
  • Infect other programs
  • Replicate itself
  • Encrypt itself (to hide from scanners)
  • Transform into another form (polymorphism)
  • Alter configuration settings
  • Destroy data
  • Corrupt or destroy hardware
The 6-Stage Virus Lifecycle (high-yield for exams)
  1. Design — author creates the virus (from scratch or a construction kit)
  2. Replication — virus spreads to new systems, speed depends on design
  3. Launch — the payload activates (data destruction, setting changes, etc.) once triggered
  4. Detection — security researchers notice the infection and begin analysis
  5. Incorporation — antivirus vendors build a signature and push it in an update
  6. Elimination — users apply the update and the virus is removed

Mnemonic: Dogs Run Loudly, During Intense Events → Design, Replication, Launch, Detection, Incorporation, Elimination.

⚠️ Illustrative virus concept (academic context only — never execute)

The lecture shows how trivially simple a destructive batch file can be, to illustrate why uncontrolled execution rights are dangerous:

@echo off Del c:\windows\system32\*.* Del c:\windows\*.*

Saved as virus.bat and converted with bat2com into virus.com. The lecture also mentions GUI "virus maker" kits (e.g., JPS Virus Maker, Terabit Virus Maker) that let someone pick options and generate an executable — showing how low the technical barrier can be, which is exactly why defenses matter.

Worms

A more advanced cousin of the virus. The defining trait: worms spread across networks extremely quickly, without needing a host file or user interaction.

  • Do not require a host application
  • Do not necessarily need any user interaction
  • Replicate extremely rapidly across hosts/networks
  • Consume bandwidth and resources
A virus needs you to open the door (click/run something). A worm picks the lock itself and lets itself in — then runs to the next house.

Spyware

Designed to collect and forward information about a victim's activity to a third party — silently, without consent.

Used for: targeted ads, identity theft, generating revenue, altering systems, capturing information.

Infection methods:

  • Instant Messaging (IM) — weak security controls make it an easy delivery channel
  • IRC — widespread use + ability to lure users into downloads
  • Email attachments — classic distribution method
  • Physical access — easiest way to install spyware directly
  • Browser defects — unpatched/outdated browsers are easy targets
  • Freeware — "free" downloads from untrusted sources bundle spyware
  • Websites — drive-by downloads via scripting while browsing

Adware

Displays ads, pop-ups, and nag screens; may replace browser home pages or install advertising items. Spread via software bundling or stealthy install when visiting a site.

Trojans

A Trojan looks like legitimate software but secretly gives an attacker covert access to the victim's system (named after the Trojan Horse).

Signs of a Trojan infection:

  • CD drawer opens/closes on its own
  • Screen flips or inverts
  • Screen settings change by themselves
  • Documents print with no explanation
  • Browser redirected to a strange page
  • Windows color settings change
  • Screensaver settings change
  • Mouse buttons reverse function

What an attacker can do once inside: steal data, install software, download/upload files, modify files, install keyloggers, view the screen, consume storage space, crash the system.

Three Types of Trojans
  • Remote Access Trojans (RATs) — give the attacker remote control (e.g., SubSeven, Back Orifice — older, classic examples)
  • Data Sending — captures data (files, keystrokes) and transmits it out, e.g., via email; keyloggers are common examples
  • Destructive — corrupts, erases, or destroys data; in extreme cases can damage hardware

⚠️ Common Mistakes & Traps

  • Confusing virus (needs a host/user action) with worm (self-spreading, network-based) — this is the single most common MCQ trap.
  • Thinking Trojans self-replicate — they don't define themselves by replication, they define themselves by disguise + covert access.
  • Mixing up the virus lifecycle order — remember Detection comes before Incorporation (you must find it before you can build a fix).
  • Assuming adware and spyware are identical — adware annoys (ads); spyware spies (data collection without consent). They can overlap but the defining goal differs.
  • Forgetting that rootkits are defined by evasion/hiding, not by what damage they do.

Phase 4 — Written Questions

Short Answer

  1. Define malware.
    Model answer: Malware, short for "malicious software," is any software designed to damage, disrupt, or gain unauthorized access to a system — including viruses, worms, Trojans, logic bombs, adware, and spyware.
  2. What distinguishes a worm from a virus?
    Model answer: A worm does not require a host file or user interaction to spread; it replicates automatically across networks. A virus requires a host file to attach to and typically needs some user action to trigger infection.
  3. Name three signs of a Trojan infection.
    Model answer: Any three of: CD drawer opening/closing, screen flipping/inverting, unexplained printing, browser redirects, mouse buttons reversing, screensaver/color settings changing.
  4. How does a rootkit avoid detection?
    Model answer: By hiding within core system components, renaming itself to resemble legitimate programs, and altering other files to prevent detection and interfere with normal scanning.

Long-Form

  1. Describe the full lifecycle of a virus, from creation to elimination.

    Model answer: A virus lifecycle has six stages. First, Design, where the author creates the virus from scratch or using a construction kit. Second, Replication, where the deployed virus spreads by multiplying and infecting new systems, at a speed depending on the author's intent. Third, Launch, where the virus executes its payload — such as destroying data or altering settings — once triggered by a user or predetermined action. Fourth, Detection, where security researchers and antivirus vendors identify the infection after it has been active for some time and begin analysis. Fifth, Incorporation, where antivirus makers build a signature for the virus and distribute it via product updates. Finally, Elimination, where users apply these updates to remove the virus from their systems.

  2. Compare and contrast viruses, worms, and Trojans in terms of how they spread and what defines them.

    Model answer: Viruses are defined by their need to attach to a host file and typically require user action to activate; they replicate by infecting other files. Worms are defined by independent network propagation — they need no host file and no user interaction, and they spread extremely fast while consuming bandwidth. Trojans are defined not by replication but by disguise: they appear to be legitimate software while covertly giving an attacker access, which they use to steal data, install further software, or damage the system. In short: viruses infect files, worms infect networks, and Trojans deceive users.

  3. Explain spyware's infection vectors and why each one is effective.

    Model answer: Spyware spreads through several vectors: instant messaging and IRC, which have weak security controls and wide reach; email attachments, which exploit email's role as a trusted communication medium; physical access, which lets an attacker install spyware directly without remote barriers; outdated browsers, which contain unpatched defects; freeware from untrusted sources, which can bundle spyware with the desired program; and malicious websites, which can silently install spyware via scripting during normal browsing. Each vector is effective because it exploits either a technical weakness (unpatched software) or a trust relationship (familiar apps, free downloads, browsing).
